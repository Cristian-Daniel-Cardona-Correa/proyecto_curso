--------------------------------------------------------------------------------
  PASOS PARA REPLICAR EL PROCESO
--------------------------------------------------------------------------------

1. Clonar el repositorio:
     git clone https://github.com/Cristian-Daniel-Cardona-Correa/proyecto_curso
     cd proyecto_curso
     git checkout feature/app_distribution

2. Instalar dependencias:
     flutter pub get

3. Generar APK de release:
     flutter build apk --release
     # Output: build/app/outputs/flutter-apk/app-release.apk

4. En Firebase Console (https://console.firebase.google.com/):
   a) Crear o abrir el proyecto Firebase del equipo.
   b) Registrar la app Android con applicationId: com.example.proyecto_curso
   c) Ir a App Distribution → Testers & Groups → Crear grupo "QA_Clase"
   d) Agregar tester: dduran@uceva.edu.co
   e) Ir a Releases → Upload → seleccionar app-release.apk
   f) Asignar al grupo QA_Clase → pegar Release Notes v1.0.0 → Distribute

5. Para la actualización incremental:
   a) Editar pubspec.yaml: version: 1.0.1+2
   b) Modificar algo visible en la UI (badge de versión, etc.)
   c) Volver a generar: flutter build apk --release
   d) Subir nuevo APK a Firebase con Release Notes v1.0.1

--------------------------------------------------------------------------------
